# Chrome Web Store material

- `listing.md` holds all text to paste into the Web Store dashboard, plus the submission checklist.
- `assets/` holds the five 1280x800 screenshots and the 440x280 small promo tile.
- The images are made from `docs/screenshots` and `assets/tusk.svg`.
- Regenerate them with `npm run store-assets` (it checks the pixel sizes).
- The privacy policy lives in `site/privacy.html`.
