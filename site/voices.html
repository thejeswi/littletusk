Adding a voice for Tusk

Tusk reads its answers aloud with the voices that your browser and computer provide. It cannot install a voice by itself, and it never downloads one without the family asking. If there is no voice for the chosen language, Tusk says so once and shows every answer as text instead. Everything else keeps working.

Check which voices exist

  1. Click Tusk, then Settings, then Family settings.
  2. Under Read answers aloud, look at the list of voices. Each language shows a voice name and whether it is online, or "no voice on this computer".
  3. Press 🔊 Test voice to hear the voice for the chosen language.

An online voice comes from the browser maker's service, so the text of the answer is sent there. A voice on this computer works without sending the text anywhere.

Windows 11

  1. Open Settings → Time & language → Speech.
  2. Under Voices, choose Add voices and pick the language, for example English (United Kingdom) or Deutsch (Deutschland).
  3. Wait for the download, then restart the browser and try Test voice again.

macOS

  1. Open System Settings → Accessibility → Spoken Content.
  2. Next to System Voice, choose Manage Voices.
  3. Select the language and a voice, then press Download. Restart the browser afterwards.

Linux

Chrome on Linux uses Speech Dispatcher for its voices. A family member can install it and a voice package with the software centre or a terminal:

  • Fedora / Bazzite: sudo dnf install speech-dispatcher espeak-ng
  • Ubuntu / Debian: sudo apt install speech-dispatcher espeak-ng

Then close Chrome completely and open it again. On some systems Chrome also needs to be started with --enable-speech-dispatcher. The family settings page shows whether Chrome found the voices.

Android and ChromeOS

Open the system settings, find Text-to-speech (Android) or Accessibility → Text-to-speech (ChromeOS), and install the voice data for the language. Then restart the browser.

If no voice can be added

Nothing is broken. Tusk still explains everything in the chat, and the person can read the answers. Two useful settings:

  • Leave Read answers aloud off, so Tusk does not try to speak.
  • Use the hands-free conversation: it still works, with the words shown as captions on the screen.
